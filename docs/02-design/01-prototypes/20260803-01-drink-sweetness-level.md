# ต้นแบบ UI: ตัวเลือกระดับความหวานของเครื่องดื่ม

- **วันที่:** 2026-08-03
- **สถานะ:** Draft
- **อ้างอิง requirement:** [[../../01-requirements/01-spec/20260803-02-drink-sweetness-level|20260803-02-drink-sweetness-level]]

## User Flow

1. ลูกค้าเลือกเมนูเครื่องดื่มที่ปรับความหวานได้
2. หน้าจอแสดงตัวเลือกระดับความหวาน 4 ระดับ: ไม่หวาน / หวานน้อย / หวานปกติ (เลือกไว้ล่วงหน้า) / หวานมาก
3. ลูกค้าเลือกระดับ (หรือข้ามไปใช้ค่าเริ่มต้น) แล้วกดเพิ่มลงตะกร้า
4. รายการในตะกร้าและใบสั่งแสดงระดับความหวานที่เลือกต่อท้ายชื่อเมนู

## Wireframe (low-fi, text description)

```
[ ชื่อเมนู: ลาเต้เย็น ]
ระดับความหวาน:
( ) ไม่หวาน   ( ) หวานน้อย   (•) หวานปกติ   ( ) หวานมาก
[ เพิ่มลงตะกร้า ]
```

ใบสั่งของบาริสต้า:

```
#012  ลาเต้เย็น (หวานน้อย)
```

## Design notes

- ใช้ segmented control / radio button แบบเลือกได้ 1 ค่า ไม่ใช่ dropdown เพื่อให้กดง่ายบนหน้าจอสัมผัส
- ค่าเริ่มต้น "หวานปกติ" ต้อง highlight ไว้ก่อนเสมอ
- เมนูที่ปรับความหวานไม่ได้ (เช่น เอสเปรสโซ, อเมริกาโนไม่ใส่น้ำตาล) จะไม่แสดงตัวเลือกนี้
