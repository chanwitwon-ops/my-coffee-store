# ต้นแบบ UI: ระบบแจ้งเตือนวัตถุดิบใกล้หมดสต็อก (Low Stock Alert)

- **วันที่:** 2026-08-03
- **สถานะ:** Draft
- **อ้างอิง requirement:** [[../../01-requirements/01-spec/20260803-03-low-stock-alert|20260803-03-low-stock-alert]]

## User Flow (ผู้จัดการ — จัดการ master list และเกณฑ์)

1. ผู้จัดการเข้าเมนู "จัดการวัตถุดิบ" เห็นรายการวัตถุดิบทั้งหมด (เพิ่ม/แก้ไข/ลบได้)
2. เพิ่มวัตถุดิบใหม่: ระบุชื่อ, หน่วย (เช่น ลิตร, กิโลกรัม, ใบ), เกณฑ์ขั้นต่ำ ("ใกล้หมด")
3. แก้ไข/ลบวัตถุดิบที่มีอยู่ได้จากหน้าเดียวกัน

## User Flow (บาริสต้า/ผู้จัดการ — กรอกจำนวนคงเหลือ)

1. เข้าเมนู "จำนวนคงเหลือวัตถุดิบ" เห็นรายการวัตถุดิบทั้งหมดพร้อมจำนวนคงเหลือปัจจุบัน
2. กรอก/แก้ไขจำนวนคงเหลือของวัตถุดิบแต่ละรายการ (manual)
3. รายการที่จำนวนคงเหลือ ≤ เกณฑ์ขั้นต่ำ จะถูก highlight ทันทีในหน้านี้

## User Flow (แจ้งเตือนบน dashboard)

1. Dashboard หลัก (หน้าเดียวกับที่บาริสต้า/ผู้จัดการใช้ดูคิวออร์เดอร์) มี widget "วัตถุดิบใกล้หมด" แสดงรายชื่อวัตถุดิบที่ต่ำกว่าเกณฑ์
2. ทั้งบาริสต้าและผู้จัดการเห็น widget นี้เหมือนกัน

## Wireframe (low-fi, text description)

```
[ หน้าจัดการวัตถุดิบ — ผู้จัดการเท่านั้น ]
วัตถุดิบ        หน่วย   เกณฑ์ขั้นต่ำ
เมล็ดกาแฟ       กก.     5           [แก้ไข] [ลบ]
นมสด            ลิตร    10          [แก้ไข] [ลบ]
แก้วเย็น 16oz    ใบ      50          [แก้ไข] [ลบ]
[ + เพิ่มวัตถุดิบ ]
```

```
[ หน้ากรอกจำนวนคงเหลือ — บาริสต้า/ผู้จัดการ ]
วัตถุดิบ        คงเหลือ      เกณฑ์
เมล็ดกาแฟ       [ 4.5 ] กก.   (5)   ⚠ ใกล้หมด
นมสด            [ 18  ] ลิตร  (10)
แก้วเย็น 16oz    [ 60  ] ใบ    (50)
[ บันทึก ]
```

```
[ Widget บน dashboard หลัก ]
⚠ วัตถุดิบใกล้หมด (1)
- เมล็ดกาแฟ: เหลือ 4.5 กก. (เกณฑ์ 5 กก.)
```

## Design notes

- หน้า "จัดการวัตถุดิบ" (เพิ่ม/แก้ไข/ลบ + ตั้งเกณฑ์) เข้าได้เฉพาะผู้จัดการ
- หน้า "กรอกจำนวนคงเหลือ" เข้าได้ทั้งบาริสต้าและผู้จัดการ
- widget แจ้งเตือนบน dashboard เห็นเหมือนกันทั้ง 2 role ไม่ต้องมี UI แยก
- ไม่มีการแจ้งเตือนแบบ push/pop-up ข้ามหน้า — ต้องเปิดดู dashboard เพื่อเห็น (ตามขอบเขตที่ไม่รวมช่องทางภายนอก)
