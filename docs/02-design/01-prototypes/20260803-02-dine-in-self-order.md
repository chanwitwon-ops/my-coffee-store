# ต้นแบบ UI: ระบบสั่งอาหารด้วยตนเองจากโต๊ะ (Dine-in Self-Order)

- **วันที่:** 2026-08-03
- **สถานะ:** Draft
- **อ้างอิง requirement:** [[../../01-requirements/01-spec/20260803-01-dine-in-self-order|20260803-01-dine-in-self-order]]

## User Flow (ฝั่งลูกค้า)

1. ลูกค้าสแกน QR ที่โต๊ะ → เปิดหน้าเว็บเมนู ระบบรู้หมายเลขโต๊ะจาก QR ทันที
2. เลือกเมนู ปรับแต่งตัวเลือก (ไซส์, ความหวาน, ช็อต, ชนิดนม) ใส่ตะกร้า
3. ตะกร้าเป็น **ตะกร้าเดียวของโต๊ะ** — ถ้ามีคนอื่นที่โต๊ะเดียวกันสแกน QR พร้อมกัน จะเห็น/แก้ไขตะกร้าเดียวกัน (แชร์ real-time)
4. กดยืนยันออร์เดอร์ — **ไม่มีขั้นตอนจ่ายเงินในระบบ** ออร์เดอร์ถูกส่งเข้าคิวบาริสต้า/ครัวทันที
5. ลูกค้าเห็นสถานะออร์เดอร์ของโต๊ะตนเองแบบเรียลไทม์ ("รอทำ" → "กำลังทำ" → "เสร็จแล้ว/เสิร์ฟแล้ว")
6. ลูกค้าจ่ายเงินที่เคาน์เตอร์ (เงินสด/บัตร) ตามปกติของร้าน

## User Flow (ฝั่งพนักงาน)

1. หน้าจอ/คอมพิวเตอร์เคาน์เตอร์แสดงคิวออร์เดอร์แบบเรียลไทม์ เรียงตามเวลาที่เข้ามา พร้อมหมายเลขโต๊ะ
2. พนักงาน/บาริสต้ากดอัปเดตสถานะออร์เดอร์ตามขั้นตอนการทำ
3. เมื่อลูกค้าจ่ายเงินที่เคาน์เตอร์ พนักงานกดปุ่ม "จ่ายแล้ว" บนออร์เดอร์นั้น
4. ถ้า QR/เน็ตที่โต๊ะขัดข้อง: พนักงานกดปุ่ม "สร้างออร์เดอร์แทนลูกค้า" เลือกหมายเลขโต๊ะเอง แล้วกรอกรายการที่ลูกค้าสั่งปากเปล่า เข้าสู่คิวเดียวกับออร์เดอร์ปกติ
5. ผู้จัดการเห็นแดชบอร์ดเดียวกัน + แถบสรุปยอดขายวันนี้ (ยอดรวม, จำนวนออร์เดอร์, แยกตามสถานะออร์เดอร์/การจ่ายเงิน)

## Wireframe (low-fi, text description)

```
[ หน้าลูกค้า ]
โต๊ะ #5
[ ลาเต้เย็น  x1  หวานน้อย ]  [ลบ]
[ ครัวซองต์  x2         ]  [ลบ]
ยอดรวม: (แสดงราคา แต่ไม่มีปุ่มจ่ายเงิน)
[ ยืนยันออร์เดอร์ ]
> จ่ายเงินที่เคาน์เตอร์นะครับ/ค่ะ
```

```
[ หน้าจอพนักงาน/เคาน์เตอร์ ]
คิวออร์เดอร์                         [+ สร้างออร์เดอร์แทนลูกค้า]
#012  โต๊ะ 5   ลาเต้เย็น(หวานน้อย) x1, ครัวซองต์ x2   [กำลังทำ ▾]  จ่ายเงิน:[ยังไม่จ่าย ▾]
#013  โต๊ะ 2   อเมริกาโน x1                              [รอทำ ▾]    จ่ายเงิน:[ยังไม่จ่าย ▾]

--- เฉพาะผู้จัดการ ---
สรุปยอดขายวันนี้: ฿4,850 | 32 ออร์เดอร์ | รอทำ 3 / กำลังทำ 2 / เสร็จแล้ว 27 | ยังไม่จ่าย 2
```

## Design notes

- ตะกร้า/ออร์เดอร์ผูกกับ "โต๊ะ" ไม่ใช่ "ลูกค้ารายคน" — ต้อง sync แบบ real-time ระหว่างอุปกรณ์หลายเครื่องที่ join โต๊ะเดียวกัน
- ปุ่ม "จ่ายเงิน" ที่ฝั่งพนักงานเป็น toggle ธรรมดา ไม่ผูกกับ payment gateway ใดๆ
- ปุ่ม "สร้างออร์เดอร์แทนลูกค้า" ต้องเลือกโต๊ะจาก dropdown/รายการโต๊ะทั้งหมด แล้วใช้หน้าจอเลือกเมนูแบบเดียวกับที่ลูกค้าใช้
- แถบสรุปยอดขายเป็น widget เดียวบน dashboard เดิม ไม่ใช่หน้าแยก ไม่มีกราฟ/ตัวกรองช่วงเวลา
