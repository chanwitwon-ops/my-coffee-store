# ระบบแจ้งเตือนวัตถุดิบใกล้หมดสต็อก (Low Stock Alert)

- **วันที่บันทึก:** 2026-08-03
- **สถานะ:** Draft
- **อ้างอิง:** [[../01-spec/20260803-01-dine-in-self-order|ระบบสั่งอาหารด้วยตนเองจากโต๊ะ (Dine-in Self-Order System)]] (ระบุว่า "ระบบจัดการสต๊อกวัตถุดิบ" อยู่นอกขอบเขตของเอกสารนั้น)

## บริบท / ที่มา

ร้านต้องจัดการวัตถุดิบหลายชนิด (เมล็ดกาแฟ, นม, แก้ว ฯลฯ) ปัจจุบันพนักงานต้องตรวจสอบจำนวนคงเหลือด้วยตนเองและจดบันทึกแยก ทำให้บางครั้งวัตถุดิบหมดโดยไม่รู้ตัวจนกระทบการขาย requirement นี้จะให้ระบบแจ้งเตือนเมื่อวัตถุดิบเหลือถึงเกณฑ์ที่กำหนด

## ความต้องการ (Requirement)

- ผู้จัดการตั้งเกณฑ์ขั้นต่ำ (threshold) ได้เองต่อวัตถุดิบแต่ละรายการ (ไม่ใช่เปอร์เซ็นต์คงที่ทั้งระบบ)
- ระบบเทียบจำนวนคงเหลือที่มีการกรอกไว้กับเกณฑ์ที่ตั้ง ถ้าต่ำกว่าหรือเท่ากับเกณฑ์ ให้แสดงการแจ้งเตือนบน dashboard ของระบบ
- การแจ้งเตือนแสดงเฉพาะในหน้าจอ dashboard ของระบบเท่านั้น (ไม่ส่งผ่านช่องทางภายนอก เช่น LINE/อีเมลในเวอร์ชันนี้)
- จำนวนคงเหลือของวัตถุดิบมาจากการกรอกด้วยมือ (manual) โดยพนักงาน/ผู้จัดการ ระบบยังไม่ต้องมีการตัดสต็อกอัตโนมัติจากการขาย/ออร์เดอร์

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** การตั้งเกณฑ์ขั้นต่ำต่อวัตถุดิบโดยผู้จัดการ, การเปรียบเทียบจำนวนคงเหลือกับเกณฑ์, การแสดงแจ้งเตือนบน dashboard ของระบบ
- **ไม่อยู่ในขอบเขต:** ระบบตัดสต็อกอัตโนมัติจากการขาย/ออร์เดอร์, การแจ้งเตือนผ่านช่องทางภายนอก (LINE/อีเมล/SMS), รายงานวิเคราะห์การใช้วัตถุดิบ (analytics), การสั่งซื้อวัตถุดิบอัตโนมัติจากซัพพลายเออร์

## Acceptance Criteria

- [ ] ผู้จัดการสามารถตั้ง/แก้ไขเกณฑ์ขั้นต่ำ ("ใกล้หมด") ได้ต่อวัตถุดิบแต่ละรายการ
- [ ] เมื่อจำนวนคงเหลือของวัตถุดิบที่กรอกไว้ต่ำกว่าหรือเท่ากับเกณฑ์ที่ตั้ง ระบบแสดงการแจ้งเตือนบน dashboard
- [ ] วัตถุดิบที่ยังไม่ถึงเกณฑ์ไม่แสดงแจ้งเตือน
