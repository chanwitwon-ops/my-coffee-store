# ระบบแจ้งเตือนวัตถุดิบใกล้หมดสต็อก (Low Stock Alert)

- **วันที่บันทึก:** 2026-08-03
- **อัปเดตล่าสุด:** 2026-08-03 — ยืนยัน requirement แล้ว: กำหนดสิทธิ์กรอก/แก้ไขจำนวนคงเหลือ, ผู้เห็นแจ้งเตือน, และเพิ่มขอบเขต CRUD รายการวัตถุดิบ (master list) ส่งต่อไปทำ design ที่ [[../../02-design/01-prototypes/20260803-03-low-stock-alert|01-prototypes]] และ [[../../02-design/02-technical/20260803-03-low-stock-alert|02-technical]]
- **สถานะ:** Confirmed
- **อ้างอิง:** [[../01-spec/20260803-01-dine-in-self-order|ระบบสั่งอาหารด้วยตนเองจากโต๊ะ (Dine-in Self-Order System)]] (ระบุว่า "ระบบจัดการสต๊อกวัตถุดิบ" อยู่นอกขอบเขตของเอกสารนั้น)

## บริบท / ที่มา

ร้านต้องจัดการวัตถุดิบหลายชนิด (เมล็ดกาแฟ, นม, แก้ว ฯลฯ) ปัจจุบันพนักงานต้องตรวจสอบจำนวนคงเหลือด้วยตนเองและจดบันทึกแยก ทำให้บางครั้งวัตถุดิบหมดโดยไม่รู้ตัวจนกระทบการขาย requirement นี้จะให้ระบบแจ้งเตือนเมื่อวัตถุดิบเหลือถึงเกณฑ์ที่กำหนด

## ความต้องการ (Requirement)

- **รายการวัตถุดิบ (Master List):** ผู้จัดการเพิ่ม/แก้ไข/ลบรายการวัตถุดิบในระบบได้ (เช่น เมล็ดกาแฟ, นม, แก้ว) — เป็นข้อมูลพื้นฐานที่ต้องมีก่อนจะตั้งเกณฑ์/กรอกจำนวนคงเหลือได้
- ผู้จัดการตั้งเกณฑ์ขั้นต่ำ (threshold) ได้เองต่อวัตถุดิบแต่ละรายการ (ไม่ใช่เปอร์เซ็นต์คงที่ทั้งระบบ) — สิทธิ์นี้เฉพาะผู้จัดการเท่านั้น
- **บาริสต้าและผู้จัดการทั้งคู่** กรอก/แก้ไขจำนวนคงเหลือของวัตถุดิบได้ (เพราะเป็นงานหน้าร้านที่ต้องทำบ่อย)
- ระบบเทียบจำนวนคงเหลือที่มีการกรอกไว้กับเกณฑ์ที่ตั้ง ถ้าต่ำกว่าหรือเท่ากับเกณฑ์ ให้แสดงการแจ้งเตือนบน dashboard ของระบบ
- **บาริสต้าและผู้จัดการทั้งคู่เห็นการแจ้งเตือน** บน dashboard (ไม่ใช่ผู้จัดการเท่านั้น เพราะบาริสต้าอยู่หน้าร้านและใช้วัตถุดิบจริง)
- การแจ้งเตือนแสดงเฉพาะในหน้าจอ dashboard ของระบบเท่านั้น (ไม่ส่งผ่านช่องทางภายนอก เช่น LINE/อีเมลในเวอร์ชันนี้)
- จำนวนคงเหลือของวัตถุดิบมาจากการกรอกด้วยมือ (manual) โดยพนักงาน/ผู้จัดการ ระบบยังไม่ต้องมีการตัดสต็อกอัตโนมัติจากการขาย/ออร์เดอร์

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** CRUD รายการวัตถุดิบ (master list) โดยผู้จัดการ, การตั้งเกณฑ์ขั้นต่ำต่อวัตถุดิบโดยผู้จัดการ, การกรอกจำนวนคงเหลือโดยบาริสต้า/ผู้จัดการ, การเปรียบเทียบจำนวนคงเหลือกับเกณฑ์, การแสดงแจ้งเตือนบน dashboard ให้ทั้งบาริสต้าและผู้จัดการเห็น
- **ไม่อยู่ในขอบเขต:** ระบบตัดสต็อกอัตโนมัติจากการขาย/ออร์เดอร์, การแจ้งเตือนผ่านช่องทางภายนอก (LINE/อีเมล/SMS), รายงานวิเคราะห์การใช้วัตถุดิบ (analytics), การสั่งซื้อวัตถุดิบอัตโนมัติจากซัพพลายเออร์

## Acceptance Criteria

- [ ] ผู้จัดการสามารถเพิ่ม/แก้ไข/ลบรายการวัตถุดิบในระบบได้
- [ ] ผู้จัดการสามารถตั้ง/แก้ไขเกณฑ์ขั้นต่ำ ("ใกล้หมด") ได้ต่อวัตถุดิบแต่ละรายการ
- [ ] บาริสต้าและผู้จัดการสามารถกรอก/แก้ไขจำนวนคงเหลือของวัตถุดิบได้
- [ ] เมื่อจำนวนคงเหลือของวัตถุดิบที่กรอกไว้ต่ำกว่าหรือเท่ากับเกณฑ์ที่ตั้ง ระบบแสดงการแจ้งเตือนบน dashboard ให้ทั้งบาริสต้าและผู้จัดการเห็น
- [ ] วัตถุดิบที่ยังไม่ถึงเกณฑ์ไม่แสดงแจ้งเตือน
