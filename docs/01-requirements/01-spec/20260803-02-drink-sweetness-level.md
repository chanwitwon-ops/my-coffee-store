# ตัวเลือกระดับความหวานของเครื่องดื่ม (Drink Sweetness Level Option)

- **วันที่บันทึก:** 2026-08-03
- **สถานะ:** Confirmed
- **อ้างอิง:** -

> อัปเดต 2026-08-03: ยืนยัน requirement แล้ว ส่งต่อไปทำ design ที่ [[../../02-design/01-prototypes/20260803-01-drink-sweetness-level|01-prototypes]] และ [[../../02-design/02-technical/20260803-01-drink-sweetness-level|02-technical]]

## บริบท / ที่มา

ลูกค้าหลายคนต้องการปรับความหวานของเครื่องดื่ม (เช่น หวานน้อย, หวานปกติ, ไม่หวาน) แต่ระบบสั่งซื้อปัจจุบันยังไม่มีช่องให้เลือก ทำให้พนักงานต้องจดบันทึกแยกและเกิดความผิดพลาดได้

## ความต้องการ (Requirement)

เพิ่มตัวเลือกระดับความหวาน (ไม่หวาน / หวานน้อย / หวานปกติ / หวานมาก) ให้เลือกได้ตอนสั่งเครื่องดื่มทุกชนิดที่ปรับความหวานได้ ค่าเริ่มต้นคือ "หวานปกติ" ตัวเลือกนี้ต้องถูกส่งต่อไปแสดงในใบสั่ง (order ticket) ที่บาริสต้าเห็น

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** ตัวเลือกความหวานสำหรับเมนูเครื่องดื่มที่ปรับความหวานได้, การแสดงผลในใบสั่งของบาริสต้า, ค่าเริ่มต้นของระบบ
- **ไม่อยู่ในขอบเขต:** การคิดราคาต่างกันตามระดับความหวาน, การปรับความหวานแบบระบุเป็น % เอง

## Acceptance Criteria

- [ ] ลูกค้าเลือกระดับความหวานได้ 4 ระดับตอนสั่งเครื่องดื่มที่ปรับความหวานได้
- [ ] ถ้าไม่เลือก ระบบใช้ค่าเริ่มต้น "หวานปกติ"
- [ ] ใบสั่งที่บาริสต้าเห็นแสดงระดับความหวานที่เลือกชัดเจน
